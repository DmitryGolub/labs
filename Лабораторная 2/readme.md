# Описание программы

Программа решает несколько задач, демонстрируя использование функций для выполнения различных операций, таких как приветствие, вычисление квадрата числа, нахождение наибольшего из двух чисел, описание человека и проверка простого числа.

## Задачи

### 1. Задание 1

#### Функция `greet(name)`

- Принимает одно строковое значение — имя пользователя.
- Выводит приветственное сообщение в формате: `Hello, {name}`.

#### Функция `square(number)`

- Принимает одно число.
- Возвращает квадрат числа, то есть результат возведения в степень 2.

#### Функция `max_to_two(number_first, number_second)`

- Принимает два числа.
- Возвращает большее из двух введенных чисел.

### 2. Задание 2

#### Функция `describe_person(name, age=30)`

- Принимает два аргумента:
  - `name` — имя пользователя (строка),
  - `age` — возраст пользователя (целое число, по умолчанию 30).
- Выводит сообщение о пользователе: `Your name: {name}. Your age: {age}`.

#### Функция `is_prime(number)`

- Принимает одно число и проверяет, является ли оно простым.
  - Простое число — это число больше 1, которое делится только на 1 и на себя.
- Возвращает `True`, если число простое, и `False`, если оно не простое.
  - Число 1 и все четные числа, кроме 2, не являются простыми.
