# Описание программы

Программа демонстрирует использование ООП (Объектно-Ориентированного Программирования) в Python, включая создание классов с методами для валидации данных, работу с инкапсуляцией, наследованием и полиморфизмом.

## Задачи

### 1. Класс `UserAccount`

Класс `UserAccount` моделирует учетную запись пользователя с возможностью валидации данных.

#### Атрибуты:
- `username` — имя пользователя.
- `email` — email пользователя.
- `__password` — пароль пользователя (с инкапсуляцией).

#### Методы:
- `set_password(new_password)` — изменяет пароль, проверяя его на соответствие правилам (минимум 6 символов).
- `check_password(password)` — проверяет, совпадает ли введенный пароль с сохраненным.
- Валидация данных осуществляется с помощью классовых методов:
  - `validator_username(data)` — проверяет имя пользователя на тип и минимальную длину (2 символа).
  - `validator_email(data)` — проверяет email на правильность формата с использованием регулярных выражений.
  - `validator_password(data)` — проверяет пароль на тип и минимальную длину (6 символов).

### 2. Классы `Vehicle` и `Car`

#### Класс `Vehicle`

- Представляет базовый класс для транспортных средств.
- Имеет атрибуты:
  - `__mark` — марка автомобиля.
  - `__model` — модель автомобиля.
  
- Метод `get_info` возвращает информацию о транспортном средстве.

#### Класс `Car` (наследник от `Vehicle`)

- Наследует все атрибуты и методы от класса `Vehicle`.
- Добавляется новый атрибут:
  - `fuel_type` — тип топлива (например, бензин).
  
- Метод `get_info` переопределяется для того, чтобы добавить информацию о типе топлива.
