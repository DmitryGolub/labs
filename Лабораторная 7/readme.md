# Описание программы

Программа демонстрирует принципы объектно-ориентированного программирования (ООП) в Python, такие как наследование, многократное наследование, инкапсуляция и полиморфизм. В программе создаются классы, моделирующие сотрудников, менеджеров и технических специалистов компании, а также демонстрируется создание команды и управление проектами.

## Задачи

### 1. Класс `Employee`

Класс `Employee` представляет базового сотрудника компании и содержит следующие атрибуты:
- `_id_employee` — идентификатор сотрудника.
- `_name` — имя сотрудника.

Метод `get_info` возвращает информацию о сотруднике в формате: `Employee: id - {id_employee} name - {name}`.

### 2. Класс `Manager` (наследуется от `Employee`)

Класс `Manager` наследует атрибуты и методы от класса `Employee` и добавляет свойство:
- `_department` — отдел, в котором работает менеджер.

Метод `get_info` переопределяется, чтобы включать информацию о департаменте. Также добавлен метод `manage_project`, который возвращает информацию о проекте, которым управляет менеджер.

### 3. Класс `Technical` (наследуется от `Employee`)

Класс `Technical` наследует от `Employee` и добавляет атрибут:
- `_specialization` — специальность технического специалиста.

Метод `get_info` переопределяется для вывода информации о специализации. Также добавлен метод `perform_maintenance`, который выводит информацию о выполнении технического обслуживания.

### 4. Класс `TechManager` (многократное наследование от `Manager` и `Technical`)

Класс `TechManager` является сочетанием классов `Manager` и `Technical` и представляет собой менеджера, который также обладает технической специализацией. Класс включает:
- Атрибут `_team`, который хранит список сотрудников в команде.
- Метод `add_employee`, который добавляет сотрудника в команду.
- Переопределенный метод `get_info`, который выводит информацию о менеджере, включая специализацию и отдел.
- Метод `get_team_info`, который выводит информацию о всех сотрудниках в команде.

### 5. Пример использования

Программа создает объект `TechManager`, а затем добавляет в его команду объекты классов `Employee`, `Manager` и `Technical`. Каждый из сотрудников получает свою информацию, и менеджер может вывести информацию о своей команде.

```python
tm = TechManager(12, "sdf", department="12", specialization="programmer")
e1 = Employee(1, "Dima")
e2 = Employee(2, "Ivan")
e3 = Employee(3, "Dasha")
m1 = Manager(4, "Anton", department="12")
t1 = Technical(5, "Vlad", specialization="programmer")
```
Менеджер может управлять проектами, а технический специалист может выполнять обслуживание. TechManager может управлять проектами, а также добавлять сотрудников в свою команду и получать информацию о них.

###  6. Многократное наследование
Класс TechManager использует многократное наследование, наследуя сразу два класса: Manager и Technical. Это позволяет объединить функциональность менеджера и технического специалиста в одном объекте.
Метод get_info переопределен в классе TechManager, чтобы включать как информацию о департаменте (от менеджера), так и специализацию (от технического специалиста).
