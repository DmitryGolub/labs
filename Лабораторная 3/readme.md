# Описание программы

Программа решает несколько задач, связанных с работой с файлами, включая чтение содержимого файлов и запись данных в файл.

## Задачи

### 1. Задание 1 — Чтение файла разными способами

Программа демонстрирует два способа чтения содержимого текстового файла:

#### Первый способ: Чтение всего файла

- Открывается файл для чтения с использованием кодировки UTF-8.
- Прочитывается все содержимое файла с помощью метода `read()`, и текст выводится на экран.

#### Второй способ: Чтение построчно

- Открывается тот же файл для чтения.
- Содержимое файла читается построчно с помощью цикла `for`, и каждая строка выводится на экран.

### 2. Задание 2 — Запись пользовательского ввода в файл

Программа записывает данные, введенные пользователем, в текстовый файл.

- Программа предлагает пользователю вводить текст.
- Каждый введенный текст записывается в файл `user_input.txt` (создается или дописывается в существующий файл).
- Для завершения ввода пользователь должен ввести команду `/end`.

### 3. Задание 3 — Запись пользовательского ввода с обработкой ошибки

Программа выполняет ту же задачу, что и в Задании 2, но с добавлением обработки ошибки.

- Если файл для записи не найден, программа выведет сообщение об ошибке `FileNotFoundError`.
- Ввод текста продолжается до тех пор, пока пользователь не введет команду `/end`.
