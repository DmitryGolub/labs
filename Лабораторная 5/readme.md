# Описание программы

Программа демонстрирует создание классов в Python, инкапсуляцию, а также работу с методами и аттрибутами класса.

## Задачи

### 1. Класс `Book`

Класс `Book` представляет собой простую модель книги и содержит следующие атрибуты:

- `title` — название книги.
- `author` — автор книги.
- `year` — год издания книги.

#### Метод `get_info`

Метод `get_info` возвращает строку, содержащую информацию о книге в формате: `Название: {title}, Автор: {author}, Год издания: {year}`.

Пример использования:
- После создания объекта `book` и присвоения значений атрибутам, вызывается метод `get_info`, который выводит информацию о книге.

### 2. Класс `Circle`

Класс `Circle` представляет собой модель круга и использует инкапсуляцию для хранения радиуса круга.

#### Атрибуты:
- `__radius` — радиус круга. Атрибут является приватным и не может быть напрямую изменен извне.

#### Методы:
- `get_radius` — возвращает текущий радиус круга.
- `set_radius` — устанавливает радиус круга. В методе осуществляется проверка, что радиус является числом (целым или с плавающей запятой) и больше или равен 0. Если условие не выполнено, выбрасывается исключение `ValueError`.

Пример использования:
- После создания объекта `circle`, устанавливаются радиусы с помощью метода `set_radius`. Если переданный радиус некорректен (например, отрицательное число или строка), будет выброшена ошибка.
