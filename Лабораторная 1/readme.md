# Лабораторная 1

Описание лабораторной работы 1.

# Описание программы

Данная программа решает две задачи с валидацией ввода данных.

## Задачи

### 1. Первая задача — вывод чисел от 1 до заданного числа

- Программа запрашивает у пользователя ввод числа.
- Введенное значение проходит проверку с помощью функции `validator_1`, которая гарантирует, что введено целое число больше 0.
  - Если число некорректно (например, не число или меньше 1), будет выведено сообщение об ошибке, и программа предложит ввести число снова.
- После успешной валидации программа выводит все числа от 1 до введенного числа, включая его.

### 2. Вторая задача — вывод большего из двух чисел

- Программа запрашивает у пользователя ввод двух чисел.
- Каждое из чисел проверяется с помощью функции `validator_2`, которая гарантирует, что введенные значения являются числами с плавающей запятой.
  - В случае некорректного ввода (например, не число), программа предложит повторить ввод.
- После валидации чисел программа выводит большее из двух введенных чисел.

## Детали реализации

- **Функция `validator_1(data)`**: 
  - Проверяет, что введенное значение является целым числом и больше 0.
  - В случае некорректного ввода выводит сообщение об ошибке.
  
- **Функция `validator_2(data)`**: 
  - Проверяет, что введенное значение является числом с плавающей запятой.
  - В случае некорректного ввода выводит сообщение об ошибке.
