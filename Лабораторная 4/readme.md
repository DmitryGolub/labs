# Описание программы

Программа демонстрирует использование стандартных библиотек Python, а также работу с импортом модулей и пакетов.

## Задачи

### 1. Задание 1 — Использование стандартных библиотек

В этом задании программа выполняет несколько операций с использованием стандартных библиотек Python:

- Импортируется модуль `math` для выполнения математических операций.
  - Используется функция `math.sqrt(4)`, которая вычисляет квадратный корень из числа 4 и выводит результат.
  
- Импортируется модуль `datetime` для работы с датой и временем.
  - Используется функция `datetime.now()`, чтобы вывести текущую дату и время.

### 2. Задание 2 — Импорт функции из модуля

Программа демонстрирует импорт функции `get_ip` из модуля `my_module`, который находится в пакете `pack`.

- Включается импорт функции с помощью явного указания: `from pack.my_module import get_ip`.
- Функция `get_ip()` вызывается и выводится результат.

### 3. Задание 3 — Разные способы импорта

В этом задании показаны различные способы импорта:

- Импорт всех функций и переменных из модуля `my_module` с использованием `from pack.my_module import *`.
- Импорт нескольких модулей из пакета `pack` с явным указанием: `from pack import my_module, my_module2`.
- Вызов функций из разных модулей:
  - `my_module.get_ip()` — вызов функции из модуля `my_module`.
  - `my_module2.test(1, 2)` — вызов функции `test` из модуля `my_module2`.

Также показан импорт всего содержимого из пакета `pack` с использованием `from pack import *`.
